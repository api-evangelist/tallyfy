Google has no single official MCP listing. There are three separate surfaces: the consumer Gemini app Spark takes a self-serve custom MCP server URL in Connected Apps for personal accounts, the Gemini CLI extensions gallery is self-serve but unvetted and Google replaced it with Antigravity CLI for free, Pro, and Ultra users on June 18 2026, and Gemini Enterprise lets any customer connect a Streamable HTTP server themselves.
