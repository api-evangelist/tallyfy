Microsoft now certifies MCP servers directly if you are a verified publisher who owns the underlying service, and still offers the older path of wrapping your server in a declarative Copilot agent. To reach the verified partner agents in the Microsoft Copilot Agent Store, you build that agent with the Agents Toolkit, then submit the package through Partner Center. Any tenant can also self-connect your server in Copilot Studio without a submission.
